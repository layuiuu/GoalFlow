# 目标流 GoalFlow

**导入你的计划，GoalFlow 把它变成可视化日程** —— 纯前端 PWA，数据只存本机，无后端、无账号。

定位：用户自带计划（从 ChatGPT / Claude 等生成的 Markdown/文本）→ 粘贴导入 → GoalFlow 解析成「阶段大纲 + 未来 7 天任务」→ 预览微调 → 每日执行打卡 → 写复盘 → AI 动态调整未来任务（预览确认后生效）。

## 功能总览

### 计划导入（新建目标的主路径）
- 把外部 AI 生成的 Markdown/文本计划**粘贴**进来，或**选择一个 `.md` / `.txt` 文件**（文件路径能避免从聊天窗口复制时丢失换行），解析为阶段大纲 + 每日任务
- **AI 优先 + 规则兜底**：配置了 API Key 时用 AI 精准解析；无 Key 或 AI 失败时自动降级为本地规则解析。**降级不再静默**：预览页顶部会显示解析来源，AI 失败时给出原因与「重试 AI」按钮
- 解析能力：Markdown 标题/加粗小节/`一、`/`（一）`/`Week N:` → 阶段；列表与纯文本条目 → 任务；日期支持 `2026-09-15`、`9月15日`、`9.15`、`9.14–9.20`（区间）、`15号`、`Day 3`、`第3天`、`第一天`、`明天`、`周三`、`下周一`、`Mon`；识别时长（45分钟/1小时）与精力（高/中/低）；代码块内容不会被误判为任务；标题末尾的 `（15分钟·低精力）`、`（周一）` 这类标注会被自动剥离
- 导入范围覆盖整份计划（今天 → 截止日，最多 180 天 / 24 个阶段 / 300 条任务）；早于今天的任务不导入，但会在预览页逐条列出；原文没写日期的条目按顺序顺延排列
- 若内容缺少换行（复制粘贴常见），会自动按「第N周」与日期边界切分并给出提示
- 导入预览页：目标信息可改、阶段可改名/改起止日期/增删、任务可改标题/日期/时长/精力、可勾选跳过、可手动补一条；解析不了的行与超预算日期集中提示
- 没有解析到任何阶段时会按周自动生成阶段（标注「自动生成」，可删可改）
- 也可以留空计划、只填目标名称，先建一个空目标
- 内置「给 AI 的计划模板」，一键复制后丢给任何 AI 生成结构化计划
- 说明：导入的任务覆盖整个计划周期；「AI 优化」仍只调整未来 7 天（滚动窗口），更远任务会随时间进入窗口

### 多目标管理
- 创建多个目标（建议活跃不超过 5 个），每个目标独立填写：描述、类型（学习/健身/技能/阅读/其他）、截止时间、工作日与周末可用时长、当前基础、个人偏好、优先级（高/中/低）、是否核心目标 ★（最多 2 个）
- 目标列表按 进行中 / 已暂停 / 已完成 / 已归档 分段查看，支持编辑、删除、归档、暂停/恢复
- 目标详情：约束条件、阶段大纲（可勾选推进）、固定任务规则、每日任务列表、任务完成率、整体进度、AI 调整历史
- 每日预算分配概览：所有活跃目标的预算之和与全局预算对比，超出时黄色警告

### 每日任务聚合（今日页）
- 聚合所有目标的当日任务，顶部显示今日预算条（超预算红色提示 + 一键"AI 协调"）
- 三种视图：⚡智能排序（核心★ > 优先级 > 精力）、📂按目标分组、⏱按时长，选择持久化
- 每个任务显示：所属目标、标题、描述、类型/精力标签、预计时长、✅完成 / ⚠️部分完成 / ❌未完成（❌可选原因：难度超预期/时间不够/状态不佳，喂给 AI）
- 底部汇总条：总任务数、预计总时长、已完成、完成率、剩余

### AI 拆解与动态调整
- **阶段大纲**：导入解析会直接带上阶段；也可在目标详情页让 AI 重新生成 3-6 个阶段（里程碑），确认后应用
- **滚动周计划**：每次只展开"未来 7 天"的每日任务（省 Token，天然支持动态调整）；分目标拆解时 prompt 会注入"其他目标已占用时长 + 全局预算剩余"约束
- **动态调整**：分目标 / 全局两种范围；策略含延后、拆分、删减、新增、排序、跨目标协调（延后低优先级非核心目标）。**所有调整必须预览确认**，可整单拒绝（留痕），应用后可一键撤销；导入的任务（source=import）同样可被 AI 调整
- 全局调整入口：今日/计划页超载提示、计划页"全局协调"、复盘后的建议
- Mock 演示模式：无 API Key 时自动启用规则化 Mock，全流程可体验；Mock 与真实 AI 输出同一 JSON 结构

### 每日复盘
- 全局一天一次：卡点、原因、推进顺利的目标、明日期望负荷
- 可展开按目标补充备注（选填，不强制）
- 复盘要点会注入 AI 调整的上下文

### 看板（全部本地计算，零 AI）
- 全局：累计完成率、每日/每周完成率曲线（7/14/30 天）、高/中/低精力任务完成率、连续达标天数（当日完成率 ≥60% 记达标）
- 分目标：完成率、整体进度、逾期数、最近复盘备注
- 目标对比：完成率横条对比 + 最常拖延目标（过期未完成占比）

### 计划页
- 日 / 周视图；按目标 / 类型 / 筛选
- 手动新增、编辑、删除、上下移动任务
- AI 优化未来 7 天（选择范围：全局或单个目标）、AI 调整历史（含撤销）

### 设置
- 全局每日预算（工作日/周末）、默认优先级、今日视图默认模式、活跃目标数提醒阈值
- AI 模式（分目标拆解 + 聚合约束为 v1；全局统一规划为 v2 预留）、允许跨目标建议、自动协调开关
- API 配置：OpenAI 兼容（Base URL / Key / 模型 / 跨域代理前缀），内置 DeepSeek 预设；演示模式（自动/始终/关闭）；测试连接
- AI 用量统计：调用次数、Token、按价格表估算成本
- 数据：导出/导入 JSON 备份、演示数据、清空全部

## 数据模型（localStorage，前缀 `goalflow.`）

| Key | 内容 |
| --- | --- |
| `settings.v1` | 全局预算、AI 开关、API 配置、价格表 |
| `goals.v1` | 目标（含里程碑 milestones、固定任务规则 repeatRules） |
| `tasks.v1` | 任务（goalId 关联，source: ai/rule/manual/import） |
| `reviews.v1` | 全局复盘（含按目标备注 perGoalNotes） |
| `adjustlogs.v1` | AI 调整日志（含撤销数据，applied/rejected/undone） |
| `aiusage.v1` | AI 调用用量与成本 |

省 Token 设计：「每天练 30 分钟口语」这类固定任务由本地 RepeatRule 规则生成（`rules.js`），不消耗 AI；AI 只做阶段大纲、滚动 7 天计划与调整建议。

## 手机落地指南（GitHub Pages + Android）

应用是纯静态 PWA，推到 GitHub Pages 即获得免费 HTTPS，手机浏览器打开后安装到桌面即可当原生 App 用。所有资源均为相对路径，天然兼容 `用户名.github.io/仓库名/` 子路径托管。

### 第一步：上线（约 5 分钟）
1. GitHub 网页 → New repository → 命名 `goalflow` → Public → Create；
2. 上传代码（二选一）：
   - 命令行：`git remote add origin https://github.com/<你的用户名>/goalflow.git && git push -u origin main`；
   - 或仓库页「Upload files」把本项目文件按原目录结构拖拽上传；
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save；
4. 等 1–2 分钟，得到 `https://<你的用户名>.github.io/goalflow/`。

### 第二步：Android 安装
1. 手机 Chrome 打开上面的网址；
2. 菜单（⋮）→「安装应用」或「添加到主屏幕」；
3. 桌面出现 GoalFlow 图标，点开即全屏独立运行（已含离线缓存）。
> 注意：安装后的应用与 Chrome 浏览器网页的本地数据相互独立，日常请固定从主屏图标进入。

### 第三步：数据迁移（电脑 → 手机）
1. 电脑端：设置 → 「导出备份」，得到 `goalflow-backup-*.json`；
2. 传到手机（微信文件传输助手 / 数据线 / 网盘均可）；
3. 手机端：设置 → 「导入备份」选择该文件。API Key 在手机端设置页重新粘贴（Key 只存本机，不随备份明文泄露风险自负——备份 JSON 内含 Key，请勿外传该文件）。

### 日常更新
改了代码 → 递增 `sw.js` 里的 `VERSION` → push 到 GitHub → 手机重新打开应用即自动拿到新版（可在设置页观察页面变化确认）。

### iOS 备忘
需用 Safari（非微信内置浏览器）打开网址 → 分享 → 「添加到主屏幕」；主屏图标与 Safari 的本地数据相互隔离，同样建议固定入口使用。

### 安全提示
- 网址无鉴权，任何人拿到链接都能打开应用（数据与 Key 均只存在各自设备本地），链接不必公开；
- 备份 JSON 包含设置与 API Key 明文，请妥善保管，勿分享给他人。

# 或 python -m http.server 8642    # 静态托管
# 打开 http://127.0.0.1:8642

手机使用：部署到任意静态托管（GitHub Pages / Vercel / Netlify），手机浏览器打开后「添加到主屏幕」即全屏 PWA。Service Worker 需 HTTPS（或 localhost）。

## AI 配置

设置页 → API 配置：
- **DeepSeek**：Base URL `https://api.deepseek.com`，模型 `deepseek-chat`，Key 从 platform.deepseek.com 获取
- **其他厂商**：任何 OpenAI 兼容接口（智谱 GLM / 通义 / Kimi 等）改 Base URL 与模型名即可；浏览器直连若遇 CORS，可填跨域代理前缀
- **无 Key**：演示模式保持「自动」即用 Mock 跑通全部流程

调用场景（`js/ai.js`）：`outline` 生成阶段大纲、`plan` 展开 7 天任务、`adjust` 生成调整建议、`import` 解析粘贴的外部计划（失败自动降级本地规则解析）、`feedback` 复盘反馈。全部要求 JSON 输出，本地做结构校验，失败自动重试一次。

## FAQ

- **数据会丢吗？** 数据只存浏览器 localStorage。清浏览器站点数据 = 清空应用。建议定期「导出备份」。
- **AI 调整会乱改我的任务吗？** 不会。AI 只输出建议，全部改动经预览弹窗勾选确认后才生效；拒绝也留痕；应用后可在计划页一键撤销。
- **一天任务排太满怎么办？** 今日页预算条变红后点「AI 协调」，或手动把部分任务❌/到计划页移动。全局预算在设置页调整。
- **改了代码没生效？** 开发请用 `tools/devserver.py`（禁缓存）；若用过静态托管 + SW，递增 `sw.js` 的 `VERSION` 后强刷。
- **粘贴的计划解析得不对怎么办？** 导入预览页会显示解析来源（AI / 基础规则）与"未能识别的行""早于今天未导入的任务"明细；可直接改目标信息、改阶段、改任务标题/日期/时长/精力、手动补一条，也可点「重新解析」修改文本再试。若显示"AI 解析失败"，多半是 Key 无效、网络或跨域问题，修好后点「重试 AI」即可。无 Key 时用的是基础规则解析，填 API Key 后解析会更准。
- **为什么有的任务没导入？** 早于今天的任务不导入（会在预览页逐条列出，可手动补）；计划超过 180 天、24 个阶段或 300 条任务时超出部分会截断并提示。
- **粘贴后换行全没了、结果很乱？** 说明来源把换行吞掉了。程序会尝试按「第N周」与日期边界自动切分并给出提示；最稳妥的办法是让对方输出成 `.md` 文件后用「选择 .md / .txt 文件」导入。
- **核心目标是干什么的？** 最多 2 个的"主目标"：排序优先、资源冲突时 AI 优先保障它的时间。
